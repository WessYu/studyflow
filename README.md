## Visão geral

O **StudyFlow** simula um produto real de organização pessoal, com tarefas distribuídas em colunas, filtros e persistência local. O objetivo do projeto foi praticar estrutura de componentes, estado, interação do usuário e experiência visual responsiva.

---

## Funcionalidades

- Kanban com colunas **A fazer**, **Fazendo** e **Feito**
- Criação, edição e exclusão de tarefas
- Drag and drop entre colunas
- Tags por tarefa
- Filtros por texto, status e prioridade
- Persistência com `localStorage`
- Alternância entre tema dark e light
- Login simulado para fluxo de produto
- Interface responsiva para desktop e mobile

## Como rodar localmente

```bash
git clone https://github.com/WessYu/studyflow.git
cd studyflow
npm install
npm run dev
```

Depois acesse:

```txt
http://localhost:5173
```
