# StudyFlow — Kanban de Estudos

Aplicação web para organização de estudos em formato Kanban, criada para praticar desenvolvimento front-end com React, TypeScript, rotas, estado, filtros e persistência local.

O projeto simula um produto real de produtividade para estudantes, com foco em organização visual, usabilidade e fluxo simples para gerenciar tarefas de estudo.

## Visão geral

O **StudyFlow** é um Kanban de estudos com colunas, tarefas, filtros e persistência no navegador.

O objetivo do projeto foi praticar estrutura de componentes, manipulação de estado, renderização condicional, rotas, responsividade e pensamento de produto aplicado a uma ferramenta simples de organização.

---

## Funcionalidades

- Kanban com colunas de progresso
- Criação, edição e exclusão de tarefas
- Organização por status, prioridade e tags
- Filtros para encontrar tarefas rapidamente
- Persistência com `localStorage`
- Alternância entre tema dark e light
- Login simulado para fluxo de produto
- Interface responsiva para desktop e mobile

## Como rodar localmente

```bash
git clone https://github.com/WessYu/studyflow.git
cd studyflow
npm install
npm run dev
```

Depois acesse no navegador:

```txt
http://localhost:5173
```
