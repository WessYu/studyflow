# StudyFlow

Kanban de estudos feito com React e TypeScript. As tarefas são organizadas por status, prioridade e tags, com filtros e persistência no navegador.

## Funcionalidades

- Criação, edição e exclusão de tarefas
- Colunas de progresso
- Prioridades e tags
- Filtros
- Persistência com `localStorage`
- Tema claro e escuro
- Layout responsivo

## Tecnologias

- React
- TypeScript
- Vite
- React Router DOM
- ESLint

## Executando localmente

```bash
git clone https://github.com/WessYu/studyflow.git
cd studyflow
npm install
npm run dev
```

Aplicação disponível em `http://localhost:5173`.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
