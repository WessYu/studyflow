## Sobre

O **StudyFlow** organiza tarefas de estudo em um fluxo Kanban. O projeto foi construído para praticar arquitetura de componentes, TypeScript, rotas, estado, filtros e experiência responsiva em uma ferramenta de produtividade.

## Funcionalidades

- criação, edição e exclusão de tarefas;
- colunas de progresso;
- prioridade e tags;
- filtros;
- persistência com `localStorage`;
- tema claro e escuro;
- layout responsivo.

## Stack

- React
- TypeScript
- Vite
- React Router DOM
- ESLint
- `localStorage`

## Executando localmente

```bash
git clone https://github.com/WessYu/studyflow.git
cd studyflow
npm install
npm run dev
```

A aplicação fica disponível em `http://localhost:5173`.
